# dev-setup-codex-community

For a request to install this received bundle, read START-HERE.md first and follow its
environment -> preview -> apply -> verify procedure. That request authorizes the installer.
For source maintenance, read NEXT.md first, then README.md and only relevant sources.
This is a standalone, user-neutral distribution of dev-setup-codex.
Never edit the upstream checkout. Change installed harness files only through an
authorized installer or recovery command, never by editing installed source copies.
Keep Windows and macOS wrappers on the shared Python installer.
Preserve existing policy outside the managed block and unrelated skills/hooks.
Never ship account data, private working notes, fixed model pins or SSH destinations.
Run python scripts/lint.py and python -m unittest discover -s tests before delivery.
Build releases with python scripts/package.py. Do not commit, set a remote, publish,
or select an open-source license without the user's authorization.
Read wiki/index.md for mechanics and knowledge/index.md for packaging decisions.
