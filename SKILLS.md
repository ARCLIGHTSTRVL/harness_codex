# Codex Skill Catalog

Skills installed by this repo into `~/.codex/skills/`. They are direct-Codex
skills; invoke by naming the skill (`sync`, `setup-check`, `dev-setup`) or by
using the trigger phrases in each `SKILL.md`.

| Skill | Purpose |
|---|---|
| `ai-slop-cleaner` | Delete-first cleanup of AI-generated bloat while preserving behavior. |
| `ask` | Scan payloads, apply project reviewer pins and capture reported runtime identity in external review artifacts. |
| `bootstrap-doctor` | Audit optional project bootstrap hook/template drift. |
| `codebase-wiki` | Build, query, lint, and refresh codebase wiki knowledge. |
| `deep-interview` | Interview the user until an ambiguous request becomes a concrete spec. |
| `dev-setup` | Umbrella lifecycle entrypoint for this direct-Codex harness. |
| `doctor` | Project health: NEXT freshness/WIP, wiki/knowledge, context contracts, fragment debt and optional verification tools. |
| `karpathy-examples` | Concrete over-engineering and drive-by-refactor anti-pattern references. |
| `knowledge-fragment` | Capture, query, consolidate and batch-promote knowledge deltas with record-selection safeguards. |
| `knowledge-mirror` | Detect and hand-craft Korean Obsidian mirrors of project knowledge. |
| `project-init` | Initialize a durable direct-Codex project bootstrap. |
| `recall` | Search Codex session transcripts by project and query, then inspect redacted matching rows. |
| `research-kb` | Scaffold, lint, and maintain human-facing research knowledge bases. |
| `setup-check` | Read-only drift check for community source and installed policy, skills and hooks. |
| `sync` | Pull latest `dev-setup-codex` and re-apply the platform installer. |
