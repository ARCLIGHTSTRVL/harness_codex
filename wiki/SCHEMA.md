# Wiki schema

Project: portable Codex workflow distribution. Python, PowerShell and Bash.
Language: English. Audience: maintainers and coding agents. Discipline: team.
Use entities/, concepts/, comparisons/ and queries/ for code documentation.
Pages use title, created, updated, type, tags, sources and verified_at frontmatter.
Prefer symbol pins at a verified Git commit; before the first commit mark claims
UNCOMMITTED and use exact file references. Do not invent commit identity.
Tags: installer, packaging, skills, hooks, policy, state, portability, testing,
security, templates, architecture, decision, comparison, meta.
Add pages to index.md and record changes in log.md. Keep at least two relevant links
when multiple pages exist. Descriptions state contracts; source pins carry locations.
